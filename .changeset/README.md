# Changesets

Welcome to Changesets! This directory stores changesets generated by developers when modifying packages.

## How to add a changeset

When you make changes to one or more packages, run:

```bash
pnpm changeset
```

Follow the interactive prompts:

1. Select which packages have changed.
2. Choose the semver bump type (`patch`, `minor`, `major`).
3. Enter a summary description of the change.

Commit the generated markdown file along with your PR.
