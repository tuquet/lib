# Security Policy

## Supported Versions

| Package Version | Supported          |
| --------------- | ------------------ |
| 0.1.x           | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `@tuquet` packages:

1. **Do not create a public issue on GitHub.**
2. Email the maintainers directly or use GitHub Private Vulnerability Reporting via the Security tab.
3. Include details of the vulnerability, reproduction steps, and potential impact.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to remediate the issue promptly.
