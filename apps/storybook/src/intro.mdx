# Tuquet Vue UI Component Suite

Chào mừng bạn đến với tài liệu và môi trường Storybook tương tác của **Tuquet Vue UI** (`@tuquet/vue-ui`).

Môi trường này được thiết kế tinh gọn, chuẩn mực, tập trung vào bộ thành phần **Shadcn-Vue (Reka UI + Tailwind CSS v4)** và **Dynamic Form** dùng chung trên toàn hệ sinh thái Tuquet.

---

## 🎯 Triết lý Thiết kế Storybook

Thư viện tuân thủ chuẩn Storybook CSF3:
- **Tập trung vào Component thuần khiết (Pure Component):** Hiển thị giao diện Shadcn/Tailwind với hệ thống biến màu HSL (`--background`, `--foreground`, `--primary`, `--border`, `--radius`) đồng nhất giữa Light và Dark Mode.
- **Tận dụng tối đa Storybook Panels:**
  - 🎛️ **Tab Controls:** Tùy biến props và trạng thái của từng component trực tiếp trên canvas.
  - ⚡ **Tab Actions:** Theo dõi các sự kiện phát ra (`submit`, `select`, `update:modelValue`...).
  - 🧪 **Tab Interactions:** Kiểm thử hành vi người dùng tự động qua `play` function.

---

## 🏛️ Các Phân hệ Component Tiêu biểu

### 1. 📝 Dynamic Form (`Vue UI/DynamicForm`)
- Tự động sinh biểu mẫu từ định nghĩa JSON Schema / OpenAPI Schema (`x-ui-*`), hỗ trợ kiểm tra hợp lệ (validation) và bố cục responsive.

### 2. ⌨️ Command Palette (`Vue UI/Command`)
- Hộp thoại tìm kiếm và thực thi lệnh nhanh kiểu Spotlight (`Cmd+K` / `Ctrl+K`) với lọc từ khóa theo nhóm.

### 3. 📅 Range Calendar (`Vue UI/RangeCalendar`)
- Bộ chọn khoảng thời gian song song 2 tháng dựa trên `@internationalized/date` và `reka-ui`.
